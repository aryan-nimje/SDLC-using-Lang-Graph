Project: Two-Player Tic Tac Toe Game

Goals:
- Develop a Tic Tac Toe game playable by two human players.
- Implement the game with alternating turns for the players.
- Display the current game board after each move.
- Detect and announce the winner or a draw according to standard Tic Tac Toe rules.
- Maintain and display the score of previous matches during the ongoing session.
- Allow the session to continue with multiple rounds until terminated by the players.

Risks:
- Ensuring correct turn alternation and input validation.
- Properly detecting game end conditions (win/draw).
- Accurately maintaining and updating scores across rounds.

Methodology:
- Use a simple console or GUI-based interface for player inputs and game display.
- Represent the game board as a 3x3 grid.
- Implement functions to check for win conditions and draw.
- Store scores in variables that persist throughout the session.
- Loop the game rounds until players decide to quit.

This plan will guide the development of the Tic Tac Toe game to meet the specified requirements.
